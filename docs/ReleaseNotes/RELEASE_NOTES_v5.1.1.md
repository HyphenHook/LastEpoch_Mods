# LastEpoch HUD v5.1.1

Compatibility update for the November 5 Last Epoch game update (Unity 6000.4.8) and MelonLoader 0.7.3 Open-Beta. Press F3 in a zone to open the mod menu.

## Changelog

### Fixes

- Updated the patched `UnityEngine.CoreModule.dll` for the latest Last Epoch `GameAssembly.dll`, fixing the startup crash while loading the PersistentUI scene.
- Updated auto-store to use the game's current material-storage API for shards, resonances, runes, glyphs, and other crafting materials.

## Install

- Install steps are in the repository [README](https://github.com/Syncingoutt/LastEpoch_Mods/blob/master/README.md).
- Alternatively, use the [LE Hud Installer](https://github.com/TriSSec-Lab/LE-Hud-Installer) to install the mod automatically.
